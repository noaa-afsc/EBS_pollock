Introduction

This report presents a causal analysis of Eastern Bering Sea (EBS) walleye pollock recruitment. We construct a Directed Acyclic Graph (DAG) based on prior ecological knowledge and implement a Bayesian regression model using brms to quantify the influence of spawning biomass, environmental drivers, and predation on recruitment.

Causal DAG Construction

We identify key hypothesized causal variables influencing recruitment: • Spawning Biomass (SB) • Bottom Temperature • Sea Ice Extent • Zooplankton Biomass • Cannibalism • Cod Abundance • Fishing Mortality

DAG with Prior Knowledge

library(tidyverse) library(ggdag) library(dagitty)

dag <- dagitty(“dag { SeaIce -> BottomTemp BottomTemp -> Zooplankton Zooplankton -> Recruitment BottomTemp -> Recruitment SpawningBiomass -> Recruitment SpawningBiomass -> Cannibalism Cannibalism -> Recruitment FishingMortality -> SpawningBiomass CodAbundance -> Recruitment }”)

edges <- dag_edges(dag) %>% mutate( strength = case_when( from == “SpawningBiomass” & to == “Recruitment” ~ “strong”, from == “BottomTemp” & to == “Zooplankton” ~ “strong”, from == “Zooplankton” & to == “Recruitment” ~ “medium”, from == “SeaIce” & to == “BottomTemp” ~ “strong”, from == “CodAbundance” & to == “Recruitment” ~ “weak”, TRUE ~ “hypothesized” ), linetype = recode(strength, strong = “solid”, medium = “dashed”, weak = “dotted”, hypothesized = “dotdash”) )

ggdag_status <- dag %>% tidy_dagitty() %>% left_join(edges, by = c(“from”, “to”))

ggplot(ggdag_status, aes(x = x, y = y, xend = xend, yend = yend)) + geom_dag_edges(aes(linetype = linetype), arrow_directed()) + geom_dag_point() + geom_dag_text(color = “black”) + theme_dag() + scale_linetype_identity() + labs(title = “EBS Pollock Recruitment DAG with Prior Knowledge”)

Bayesian Causal Model (brms)

We fit a Bayesian regression model of log recruitment as a function of observed and latent covariates.

Data Preparation

Simulated example dataset (replace with real data)

set.seed(123) n <- 100 pollock_data <- tibble( logRecruitment = rnorm(n, 8, 0.5), logSB = rnorm(n, 10, 0.5), BottomTemp = rnorm(n, 2, 1), Zooplankton = rnorm(n, 0, 1), CodAbundance = rnorm(n, 5, 1), Cannibalism = rnorm(n, 0.2, 0.1) )

brms Model

library(brms)

prior <- c( prior(normal(0, 1), class = “b”), prior(cauchy(0, 2), class = “sigma”) )

fit <- brm( logRecruitment ~ logSB + BottomTemp + Zooplankton + CodAbundance + Cannibalism, data = pollock_data, family = gaussian(), prior = prior, chains = 4, iter = 2000, seed = 123, control = list(adapt_delta = 0.95) )

Posterior Summaries

summary(fit)

Posterior Plots

plot(fit)

Discussion

This analysis demonstrates a basic workflow for combining prior ecological knowledge and observational data in a Bayesian causal framework. The DAG clarifies model assumptions and helps identify potential confounders. The brms model allows uncertainty quantification in regression effects.

Future work may include: • Incorporating time lags and autocorrelation structures • Modeling latent variables such as cannibalism more explicitly • Extending the model to include spatiotemporal structure in TMB or STAN
